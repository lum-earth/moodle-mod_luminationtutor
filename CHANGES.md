# Changelog

## v0.1.0 (2026-10-22)

- First release. A course activity where students ask an AI tutor questions and get answers from a document the teacher adds (PDF, DOCX or TXT).
- The tutor answers in the language of the student's question.
- One conversation per student, so the tutor remembers earlier questions. A new document starts new conversations.
- Teachers can switch the tutor off and set a daily number of questions per student (20 by default), and see how many questions were asked.
- Activity completion on view, logs, and backup and restore (conversations only with user data).
- Students' names and email addresses are never sent to the API.
- Uses the Lumination AI Provider's API key. English and Spanish.
